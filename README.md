# منصّة علم — صفحة هبوط رسمية

صفحة تعريف رسمية لمشروع **منصّة علم** (منصة تعليمية للطلاب والمعلمين)، صفحة واحدة ذاتية الاكتفاء (HTML/CSS/JS داخل ملف واحد) تدعم العربية RTL وتعمل بدون أي اتصال خارجي.

## الملفات

| الملف | الوصف |
| --- | --- |
| `index.html` | الصفحة الرئيسية (كل التنسيقات مضمّنة داخلها) |
| `.github/workflows/pages.yml` | نشر أوتوماتيكي إلى GitHub Pages عند كل push |

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح، أو استخدم أي خادم ثابت:

```bash
npx serve .
```

## النشر على GitHub Pages

1. أنشئ مستودعًا على GitHub وارفع هذا المجلد إليه (مثال: `elmam-landing`).
2. من إعدادات المستودع: **Settings ← Pages**.
3. في قسم **Build and deployment** اختر المصدر **GitHub Actions**.
4. عند كل push إلى `main` يُنشر الموقع تلقائيًا على `https://<اسمك>.github.io/<اسم-المستودع>/`.

> ملاحظة: روابط «تحميل التطبيق» للمتجر مؤقتة (`#`) — حدّثها لاحقًا بروابط التوزيع الفعلية.

## المشروع الكامل

تطبيقات الطالب والمعلم (Flutter) تقع خارج هذا المستودع في:

- `apps/teacher_app`

## الرخصة

أضف رخصة تناسبك (مثل MIT) قبل النشر الرسمي بحسب ما يقرّه فريق المشروع.
